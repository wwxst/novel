## 4. 遗留缺陷基线（迁移前必须进入任务清单）

来源：既有工程最终未修清单（内部基线）。共 **18 条可修项**（按子项计：B-17 含 2 项、B-20 含 7 项；P0=0 / P1=0 / P2=10 / P3=8）+ 8 组不可修项 + 13 个范围外域。已关闭项（B-01/B-03/B-05 至 B-12 等）不再列入。

| ID | 级别 | 位置 | 问题 | 新仓库处置 |
|---|---|---|---|---|
| B-02 | P2 | 首页/搜索/我的/书架 | 整页视觉未收敛（内容差 + 局部几何） | 以新基线重做，不承诺旧整页比率 |
| B-04 | P2 | 详情/设置 | 「关注」「简介更多」交互不完整 | 阶段三实现真实状态 |

| B-14 | P2 | 阅读器 | 空章显示 `1/0` + 空白 | 新实现必须有空态 |

| B-17 | P2 | 阅读器测试 | 28dp pitch/字号极值缺参数化断言；15 行 vs 14 行口径 | 金标扩参数化，口径唯一化 |
| B-18 | P2 | 兼容性 | minSdk 26 无取舍记录 | 统一为 minSdk 24 / target 36，并记录与旧基线 26 的差异 |

**不可修/证据缺口（8 组）**：素材差异（封面/正文/评论/热词）、自有字体与纹理、模拟器性能口径、未登录账号、书架第二屏内容量等。**新仓库用自写/自绘素材替代，不继承"不可修"结论。**

**范围外（13 域）**：短剧、听书播放器、评论/社区、下载管理、账号/会员/支付、搜索扩展、分类真实结构、我的扩展、桌面组件、深链/通知/文件导入、启动广告/兴趣选择/未成年、阅读历史部分能力、其他。已并入 §3 的 P1/P2/不做。

## 5. 当前验收结论（必须继承的诚实口径）

- 既有 Android 工程的最终整体验收为 **不达标（判否）**：整体产品验收未通过；P0/P1=0、0 crash/ANR，但存在残余 P2/P3、素材/内容差与范围缺口。
- 因此：**新 Flutter 产品不能声称"已完成/已对齐"**。正确表述是"在既有验证资产基础上重新实现，并按新验收基线逐阶段验收"。
- 页脚页码、详情页载体、阅读器单击语义等属**产品决策**，不是"实现缺陷"；必须先拍板再实现（见 `docs/10-risks-and-decisions.md`）。
