# 05 · UI 体系、状态矩阵与三端交互

> 目标：三端共用一套设计 token 与基础组件，页面**能操作、状态正确**；静态截图相似不算达标。
> 允许平台必要差异（导航形态、列数、鼠标/键盘），但 token、阅读器几何、文案、热区下限必须一致。

## 1. 屏幕与覆盖层清单

**11 个载体 + 设置页**：书城·推荐、书城·频道、分类、书架（4 子 tab）、我的、搜索（6 态）、书籍详情、阅读器正文、完整榜单、浏览历史、我的消息、设置。

**8 个全屏层/面板**：阅读菜单、目录、阅读设置、评论、状态提示层、详情简介更多、首页负反馈、听书悬浮球。
**6 类对话框**：书架删除确认、书架 ⋮ 菜单、阅读器 ⋮ 菜单、阅读设置 5 处确认、历史清空确认、启动门。

> 旧口径"12 屏"把主壳与其 4 个 tab 重复计数；设计基线里的"短剧 tab"已由"分类 tab"替代。

## 2. 设计 token 单一源

```
design/tokens/
  ui.tokens.json        # primitives + 语义别名（唯一手写源）
  reader.themes.json    # 7 档阅读主题
  shell.skin.json       # 日/夜外壳语义
  breakpoints.json      # 断点与内容最大宽度
tools/gen_tokens.dart   # 生成 lib/design/tokens.g.dart（禁手改）
```

四道防漂移闸门：
1. 生成物头部写入源文件 sha12，CI 重算不一致即失败；
2. `tokens_baseline_test.dart` 逐条断言基线值；
3. 字面量围栏：除生成物与 painters 白名单外，`lib/` 出现裸色值/裸字号/裸边距即失败；
4. 迁移对照测试：旧常量名→值 与生成物逐条比对，输出"缺失/改名/变值"。

## 3. 主题

- 阅读主题 7 档，默认 id=2，夜间默认 id=5；切换主题只换色、不重排、不进布局指纹。
- 外壳日/夜两套语义映射；夜间只影响外壳（首页/书架/我的/设置），阅读器使用独立纸色。
- 派生规则写进生成器（如夜间分割线 `#1FFFFFFF`），禁止页面直接引用浅色原值。
- 必须新增对比度校验（夜间空态次要按钮曾出现 ≈1.06:1 的不可读问题）。

## 6. 交互规格

- **点击**：不加 ripple/ink；选中态只靠字重+颜色；可点区域 ≥44dp。
- **长按（5 种语义，不得统一成操作菜单）**：首页书卡→负反馈弹层；书架书卡→多选；搜索历史→直接搜索；目录章节→跳章；阅读器正文→选词（新功能，移动端首版不做）。
- **双击**：无双击语义；阅读器禁止 `onDoubleTap` 抢单击。
- **滑动**：阅读器 5 模式；详情左滑开始阅读（阈值 0.35W 或 600px/s）。
- **返回**：阅读器逐层关闭（评论→设置→目录→菜单→退出）；搜索三档；非首页 tab→回书城→退出。
- **边缘手势**：正文页关闭平台边缘返回（与左右翻页冲突），起始 x≤24dp 不注册翻页。
- **弹层**：外点 + 返回逐层 + 拖拽把手；蒙层 50%/60%/0%。
- **滚动位置**：tab 与频道切换精确保留；二级页返回"保留位置 + 允许刷新重排"（待拍板）。
- **Web**：hover 仅用于可点卡片（基线无证据，需拍板）；滚轮翻页；键盘 `←/→/PgUp/PgDn/Space`；`Esc` 关层；正文必须可选中/可 `Ctrl+F`/可读屏（见 `04-reader-engine.md §8`）。

**基线约束**：既有实现无 haptic/ripple，不要擅自添加震动或水波纹；如要加，必须作为设计变更单独批准。

## 7. 三端响应式

| 档 | 宽度 | 导航 | 内容最大宽度 | 网格 |
|---|---|---|---|---|
| 手机 | <600dp | 底部纯文字 4 tab（高 44） | 全宽，页边 12/16 | feed 2 / 书架 3 |
| 平板 | 600–839dp | 底部 tab 或左侧 rail（待拍板） | 列表 640 | feed 3 / 书架 4–5 |
| 桌面/Web | ≥840dp | 顶部栏 + 左 rail 240 | 列表 720 / 正文 680 / 面板 560 | feed 4 / 书架 6 |

- 必须一致：token、阅读器内容盒与行距、锚点、文案、热区、键盘/读屏语义。
- 允许不同：导航形态、列数、卡片宽度、弹层限宽、hover/滚轮/键盘、系统手势区。
- 安全区：`MediaQuery.padding`；阅读器沉浸时顶栏取 `max(safeArea.top, 44.2dp)`。
- 旋转：阅读器不重建（`LayoutBuilder` + 锚点重排）；其他页允许重建但须恢复滚动与输入。
- 断点为新增设计，需真机/浏览器校正后才能冻结。

## 8. 视觉验收口径

1. **三套画布**：411×914@2.625、360×800@3、1280×800@1；每屏每态一帧，文件名含屏/态/画布/sha12。
2. **指标分层**：分区几何 bbox（主判据）+ 控件色值 + 文本 ink ±2px；整页 `changed_gt8` 只作趋势，不作通过判据。
3. **容差**：bbox ≤2px；色值 ≤4/通道；ink ≤2–3px；整页阈值按内容可控性分档，素材/字体差异进豁免清单。
4. **基线帧**：保留既有 010/011/014/015/017/019/020/021/022/023/024/025/026/028/031 与 1.3× 字号帧，作为迁移对照；旧图不入新仓库，只在新仓库记录测量值。
5. **门禁**：每屏至少 1 帧金标 + 几何/色值断言进 CI；整页比率不阻塞合并（避免为凑比率改 mock）。

## 10. 独立质疑后的补充（v2）

### 10.1 阅读入口（P0，必须修）
基线与既有实现都只有"左滑"唯一入口，非触摸/键盘/读屏用户无法开始阅读。修订：
- 移动端：保留左滑，同时提供可聚焦语义节点 + `Enter`/`Space` 等价动作（不改变视觉基线）。
- Web/桌面：额外显示可见的「开始阅读」按钮（响应式允许的差异），保证鼠标/键盘/读屏可发现。
- 验收：关闭触摸模拟，Tab+Enter 从首页→详情→正文可完成；读屏能读到入口语义；不得只靠手势。

### 10.2 目录弹层
基线目录含 **详情/目录/笔记三 Tab + 搜全文 + 精简/倒序**。v1 实现"目录 + 搜全文 + 排序"，"笔记" Tab 显式置灰并写"笔记功能未开放"（不得空白 Tab）；笔记功能整体延后需用户书面登记。

### 10.3 阅读菜单与设置面板
- 阅读菜单顶栏按基线 4 入口（加入书架 / 下载 / 评论红点 / 更多）；未实现项必须置灰 + 明确说明，不能静默无响应。
- 设置面板按基线 6 项（字体列表 / 背景 / 护眼 / 评论设置 / 自动阅读 / 更多）。背景纹理缺素材，v1 先做纯色/纸色，纹理面板置灰并说明。
- 自动阅读、护眼、评论设置没有实现前不放入可点击列表。

### 10.4 完整榜单
基线含"分类 Tab 6 项 + 左侧 11 类型栏"。v1 路由增加 `category` 参数（或降为页内状态），组件补"榜单分类 Tab"与"类型侧栏"；验收时点分类/侧栏必须切换内容。

### 10.5 频道数
实现为 6 频道，基线为 8 频道。v1 按 8 频道迁移，并在范围表逐项标注"做/不做/暂缺"；不得用"6 频道同构"代替。

### 10.6 手势规格（必须成文）
| 手势 | 时长/阈值 | 结果 |
|---|---|---|
| 首页书卡长按 | 800ms | 负反馈弹层 |
| 书架书卡长按 | 800ms | 进入多选 |
| 搜索历史长按 | 800ms | 直接搜索 |
| 目录章节长按 | 800ms | 跳章 |
| 正文长按 | 1100–1300ms | 划词/工具条（v1 若不做，需用户签字） |

长按后慢速上滑不得触发翻页或弹层；滚动/横滑与长按的仲裁由页面注入 `GestureSpec`。

### 10.7 返回与滚动
- Web 浏览器后退**永远离开阅读器**，不劫持为翻页。
- 阅读器返回逐层关闭覆盖层，根状态退出。
- 滚动位置：tab/频道切换精确保留；二级页返回"保留位置 + 允许刷新重排"（待拍板）。

### 10.8 状态矩阵补充 8 类
超时（与错误分开）、部分失败（目录成功/正文失败）、章节缺失、缓存过期、多设备/重装、退后台再回、字体未就绪（Web）、多标签页。每格至少 1 帧 + 文案断言；无基线标 `unverified`。

### 10.9 账号相关状态
服务端未实现前，未登录不是"可登录"状态：入口显示"账号功能未开放"说明页，不提供假登录表单；U 列按终态验收。

### 10.10 视觉判据分层（不在文档内自相矛盾）
- 硬判据：度量（页/行/锚点/usedHeight/右墨迹）+ 分区几何 bbox + 控件色值。
- 趋势指标：整页 `changed_gt8`，只记录、不阻塞、不作通过依据。
- 缺失基线的格子必须写编号并标 `unverified`；豁免清单逐帧人工确认。

### 10.11 Web hover
基线无 hover 证据，v1 **不新增** hover 态；如需加，按设计变更单独批准。
