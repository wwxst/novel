# 10 · 风险清单与需要拍板的事项

> 用法：标 **[阻塞]** 的项在阶段二开工前必须有结论；其余可在对应阶段前确认。
> Agent 不得自行决定标 **[用户]** 的事项，也不得把"未确认"写成"已确认"。

## 1. 风险

| # | 风险 | 概率/影响 | 现状证据 | 缓解 |
|---|---|---|---|---|
| R1 | Web 字体体积导致首屏不可接受 | 高/高 | 未子集字体首访 gzip 11.3MB；首访合计 13.8MB | 子集化 ≤1.2MB；App/Web 同子集；Gate 0 验证 |
| R2 | Web 正文不可选中/`Ctrl+F`/读屏（Canvas 不在 DOM） | 确定/高 | CanvasKit 渲染，原型 8 页全在 canvas | DOM 文本镜像层，阶段二必做，不可后置 |
| R3 | iOS 完全无法本机验证 | 确定/高 | 无 macOS、无 Xcode | 交代码 + `unverified`；macOS CI 或借机验证 |
| R4 | 无 Android 设备/模拟器，真机性能/手势/恢复全空 | 确定/高 | `adb devices` 空、无 emulator | 真机或云真机；否则明确标注未验证 |
| R5 | 字体子集工具链不可用/子集后分页漂移 | 中/高 | 本机未装 fontTools；子集体积为推断 | Gate 0 先做；子集后用金标复测 |
| R6 | Android 首次构建依赖公网（Maven/SDK/NDK） | 中/中 | 已成功一次（683.6s，自动装 platform36/NDK），但 `maven.google.com` 曾超时 | 预热 Gradle/SDK 缓存；锁版本；离线镜像 |
| R7 | 范围过大（Tier C 470–660 人日） | 高/高 | 11 屏三端约 420–640（P50≈500），完整产品更多 | 分层批准（A/B/C），不一次承诺 |
| R8 | 移植错误行为（指纹缺陷、页码口径、无缓存） | 中/高 | 既有实现 12 项缺陷清单 | 迁移缺陷清单 + 金标/回归断言 |
| R9 | 两端对齐/混排断行在真字体下漂移 | 中/高 | 金标仅纯 CJK；原型未实现 justify | 新增混排/标点 fixture；真字体交叉测试 |
| R10 | 状态管理/依赖过度设计 | 中/中 | Riverpod+go_router+drift+freezed 组合 | 手写 Notifier、不引 riverpod_generator；依赖逐项论证 |
| R11 | 单机 golden 基线不可持续 | 中/中 | 字体/引擎/OS 变化即全红 | golden 只做组件、Web 只做度量；基线版本化 |
| R12 | 三端验证"走空却被汇总成已验证" | 中/高 | 既有工程 androidTest 4 条从未执行 | DoD 强制 `unverified` 单列，质量角色签署 |
| R13 | 网络/CI 受限（GitHub 不可达） | 确定/中 | git 走失效代理；GitHub HTTPS 失败 | 本地/自托管 runner；macOS CI 待网络恢复 |
| R14 | 素材/字体/许可风险 | 低/高 | Mock 为自写；字体 OFL；1 个书名需改 | CI 禁项扫描；LICENSES 登记 |
| R15 | 多 Agent 并行写同一文件冲突 | 中/中 | 本阶段已按目录分派 | 写作用域表；共享文件单点负责 |
| R16 | 个人维护成本（三端+后端） | 高/中 | 单人项目 | 单包、少依赖、不做无关业务域（电商/游戏/支付/广告） |
| R17 | Web 首屏门限算术不成立（分项相加超总门限；冷加载 4.4s） | 高/高 | Chromium 路径约 3.69MB、WebKit 约 4.55MB；唯一冷加载 4,407ms | 门限分浏览器、先做四段耗时分解；Safari 范围单列决策；不承诺 2s |
| R18 | 两端对齐未实现导致像素验收失真 | 高/高 | Flutter 原型 `justif/letterSpacing` 命中 0 | S2 justify PoC + 右墨迹断言；预算 ≥6 人日 |
| R19 | 依赖解析未离线验证（9 个直接依赖本地无缓存） | 中/高 | pub cache 无 riverpod/go_router/drift/freezed | S0 预拉依赖 + `pub get --offline` 硬门禁 |
| R20 | Web 默认零离线缓存（内置 SW 自杀） | 高/中 | `flutter_service_worker.js` 815B 且注销自身 | 自建 SW 单列 8–12 人日；验收"断网刷新可读已缓存章节" |
| R21 | Flutter 3.50 弃用 `package:flutter/material.dart` | 中/中 | SDK 源文件 `@Deprecated`，模板改用 `material_ui` | 依赖加 `material_ui`，全部 import 走新包；analyze --fatal-infos 先跑通 |

## 3. 已由方案默认锁定、需用户知情的事项

1. 单包架构、Riverpod、go_router、drift（探针后可能切 sembast）、`material_ui`；**不引 freezed**。
2. 仓库措辞只呈现自研实现与设计数值，不引用第三方应用名称与研究过程。
3. 不做电商/支付/广告/游戏/创作发布等非阅读域（若要做需单独立项）。
4. 账号/同步/云书架在服务端实现前不提供，相关入口显示"功能未开放"，不预写同步代码与空实现。
5. 既有参考工程保持只读，不删除、不迁移进新仓库。
6. Android `compileSdk/targetSdk 36`、`minSdk 24`（已由实测构建验证；如要 26 需单独说明）。
7. v1 阅读器字体只保留"1 个打包子集 + 系统字体"；4 家族字体、桌面双栏等作为后续扩展。
8. Web v1 固定 dart2js + CanvasKit 自托管；wasm 作为独立分支，不默认启用。
9. 像素金标只做趋势，硬判据为度量 + 分区几何/色值；此决定须在阶段二前写入判据文件。
