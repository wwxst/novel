## 1. 硬判据（通过/失败只看这些）

### 1.1 分页度量（纯 Dart / Flutter / Web 同值）

| 指标 | 值 | 断言方式 |
|---|---|---|
| 页数 | 8 | 精确相等 |
| 正文行数 | 94 | 精确相等 |
| 每页行数 | `[10,0,14,14,14,14,14,14]` | 数组精确相等 |
| 每页首行字数 | `[13,0,13,4,8,5,15,13]` | 数组精确相等 |
| 页首锚点 | `(null,0) (4,0) (5,0) (9,28) (14,28) (19,28) (24,13) (29,0)` | 逐项相等 |
| 行 pitch | 52.5714dp | `closeTo(…, 1e-3)` |
| 内容盒高 | 2187/2.625dp | `closeTo(…, 0.01)` |
| usedHeight | `[653.83,0,812.19,831.24,831.24,831.24,812.19,812.19]` dp | 逐项 ±0.01 |
| 两端对齐右墨迹 | 与参照 ≤2px | 仅真渲染通道 |

| 指标 | 容差 |
|---|---|

### 1.3 功能与数据

| 判据 | 方式 |
|---|---|
| 加入书架 / 删除 / 置顶 / 进度保存 | 操作前后 DB/prefs 有命令输出差值 |

### 1.4 交互与可访问性

| 判据 | 方式 |
|---|---|
| 键盘进入阅读器 | 关闭触摸模拟，Tab+Enter 从首页→详情→正文 |

| 返回语义 | Web 后退离开阅读器；Android 返回逐层关层后退出 |

## 2. 趋势指标（不参与通过判定）

- 整页 `changed_gt8`：只记录，不阻塞合并，不据此宣称"高保真"。
- 冷启动时间：分浏览器/设备记录，用于优化排序，不作为单次发布门禁。
- 阅读器内存曲线：记录 PSS 峰值，用于回归对比。

## 3. 三端验证矩阵

- 状态对象 **15 行**（搜索拆入口/联想/结果 3 行；阅读器正文、菜单/目录/设置面板分行；含设置）× 7 态 × 3 端 = **315 格**。
- 每格状态：`PASS` / `FAIL` / `unverified` / `N/A(附理由)`。
- 报告必须输出 `unverified_cells=NNN/315`；`unverified` 不计通过。
- 无 Android 设备/模拟器或 macOS 时，阶段五不得判定通过。

## 4. 阶段二出口（Tier A）

1. 金标 8 页/94 行/锚点/usedHeight 在纯 Dart 与 Web 两列全同；Android 构建产物存在。
